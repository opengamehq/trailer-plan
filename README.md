# opengame-trailer-plan

Plan a game trailer before anything is shot, for a browser game or any engine. Covers the archetype and format, choosing and measuring the music, measuring reference trailers, mapping how to make the game filmable, the story, and a frame-exact shot list and storyboard checked against measured gates and the owner's eye.

It is one of the [OpenGame](https://opengame.io) agent skills, which teach a coding agent such
as Claude Code, Codex, Cursor or OpenCode to build a browser game and put it online.

## Install

```bash
npx skills add opengamehq/trailer-plan
```

The skill installs under its own name, `opengame-trailer-plan`. Every OpenGame skill, each under its own
name, installs from [opengamehq/opengame](https://github.com/opengamehq/opengame):

```bash
npx skills add opengamehq/opengame
```

How the skills fit into making and shipping a game is at [docs.opengame.io](https://docs.opengame.io).
